# পেজ ডিজাইন রেফারেন্স

প্রতিটা পেজের জন্য একটা করে ফাইল। প্রতিটা ফাইলই ওই পেজের **ব্রিফ** আর
**রেকর্ড** — পেজটা কী কাজে, কোন সেকশন কোন ক্রমে আছে, কীভাবে ডিজাইন করতে হবে,
আর কী কী এখনো ঠিক হয়নি।

## নিয়ম

- ফাইলের নাম হবে রুটের নাম, ছোট হাতের, স্ল্যাশের বদলে ড্যাশ:
  `/` → `home.md`, `/product/[slug]` → `product-detail.md`, `/about` → `about.md`
- সেকশনগুলো নাম্বার করা থাকবে **যে ক্রমে দর্শক দেখে** সেই ক্রমে
- প্রতিটা সেকশনে যথাসম্ভব একই কাঠামো —
  **উদ্দেশ্য · গঠন · বিষয়বস্তু · আচরণ · অ্যাসেট**
- যা এখনো ঠিক হয়নি সেটা নিচে **বাকি কাজ** অংশে। ওই তালিকাটাই পেজের টু-ডু।

## হোমপেজ ডিজাইন কনস্ট্যান্ট (সব সেকশনে)

লাইভ হোম (`/`) শেষ করার সময় এই তিনটা মাথায় রাখুন — বিস্তার [`home.md`](home.md):

1. **সেকশন↔সেকশন গ্যাপ = ৬px** (`gap-1.5` / `mt-1.5`)
2. **ইমেজ↔ইমেজ গ্যাপ = ৬px** (সেকশনের ভেতরেও একই)
3. **ফুল উইডথ** ইমেজ ব্যান্ড / সেকশন — হোমকে উপর থেকে নিচ এক “লার্জ বার” হিসেবে ফিনিশ

## কোড ফোল্ডার (মার্কেটিং ক্রোম)

```text
components/karmo/header/   ← TopHeader + Navbar + Header
components/karmo/chrome/   ← ThemeControl, section snap
components/karmo/home/     ← হোমের প্রতিটা সেকশন আলাদা ফাইল
components/karmo/about/    ← পরে, একই প্যাটার্ন
```

## এখন পর্যন্ত যা লেখা হয়েছে

| পেজ | রুট | ফাইল | অবস্থা |
|---|---|---|---|
| হোম | `/` | [home.md](home.md) | অর্গানাইজড; সেকশন-বাই-সেকশন ফিনিশিং চলছে |
| প্রোডাক্ট তালিকা | `/products`, `/shop` | — | শুরু হয়নি |
| প্রোডাক্ট ডিটেইলস | `/product/[slug]` | — | শুরু হয়নি |
| এবাউট | `/about` | — | রুট আছে `(karmo-2)/about`; কম্পোনেন্ট ফোল্ডার পরে |
